# Changelog

## Unreleased

- Added a Progression tab with Pocket City chest rewards, city policies, and quest objectives ready for in-game reward collection.
- Added Pocket City 2 research states, adopted pet well-being and follower controls, and per-event cooldown removal.
- Added tax controls and debt clearing for both games, using each game's tax units and loan representation.

## 2.0.0

- Rebuilt the desktop editor in Rust with egui and eframe.
- Added Pocket City support alongside Pocket City 2 in the same application.
- Added per-snapshot editing, copy export, and automatic backups with restore.
- Added a 13-language interface, descriptive settings labels, and a palette inspired by both games.
- Added a Pocket City 2 sandbox preview, resource automation, disabled research, and per-city survival upgrades.
- Added tag-triggered Windows release publishing with a ZIP archive and SHA-256 checksum.

Earlier versions are available in Git history.
